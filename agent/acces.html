Rejoindre votre établissement

Entrez le code d'accès que l'administrateur de votre établissement vous a transmis. Vous ne le saisirez qu'une seule fois : aux prochaines connexions, le portail s'ouvrira directement.

12 caractères, par exemple ABCD-EFGH-JKMN. Les tirets et les espaces sont facultatifs.

Pas de code ? Demandez-le à l'administrateur de votre établissement. Le code vous donne accès au portail avec le rôle Membre (Réception, Équipe technique et tableau de bord). Il ne donne aucun droit d'administration.
